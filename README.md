# Murali Manohar P - Portfolio

A simple, responsive portfolio site built with plain HTML, CSS, and JavaScript. It is ready to publish with GitHub Pages - no build process or framework required.

## Files

- `index.html` - page content and structure
- `styles.css` - responsive visual design
- `script.js` - mobile navigation, lightweight scroll reveals, and footer year
- `assets/profile-photo.png` - profile photo extracted from the supplied resume

## Before publishing

Replace each `href="#"` labelled as a replacement link in `index.html` with the actual LinkedIn, GitHub, and IEEE publication URLs. These are deliberately placeholders because the resume names the links but does not provide their URLs.

## Publish on GitHub Pages

1. Create a new GitHub repository and upload all files in this folder, including the `assets` directory.
2. In the repository, open **Settings** → **Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose the branch containing these files (usually `main`) and select the `/ (root)` folder.
5. Click **Save**. GitHub will display the public website address when deployment finishes.

For a personal GitHub profile site, name the repository `YOUR-USERNAME.github.io`; GitHub will then publish it at `https://YOUR-USERNAME.github.io`.
